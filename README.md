# Portfolio

This is a personal portfolio website built using HTML, CSS, and JavaScript, featuring neon figure designs for a modern and eye-catching visual experience. It showcases professional and technical skills, projects, about section, and contact details in an interactive and stylish manner.

## Features
- **Modern UI Design**: Neon figure aesthetics for a sleek and dynamic look.
- **Responsive Layout**: Works across all devices and screen sizes.
- **Interactive Elements**: Smooth animations and transitions.
- **Showcase Projects**: Display personal and technical projects.
- **Professional & Technical Skills**: Highlight expertise in various domains.
- **About Section**: Brief introduction and background information.
- **Contact Section**: Easy way to connect via email or social media.
- **Deployed Online**: Accessible at [Portfolio](https://someshwar28mishra.github.io/Portfolio/).

## Installation

Clone the repository and navigate to the project directory:
```sh
git clone <repository-url>
cd portfolio
```

Open `index.html` in a browser:
```sh
open index.html
```

## Technologies Used
- **HTML** – Structure of the webpage
- **CSS** – Styling and layout design
- **JavaScript** – Interactive elements and animations
